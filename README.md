**项目背景

为了守卫班级的和平与安全，我决定开发一套预警防御系统。
因为这位老师的外号（之一）叫“家庭教师”，我们引用了《简·爱》中男主角的名字——罗切斯特 (Rochester)，作为这套装置的代号。
现在，只要汤达人的身影在后门出现，这套装置就能提前捕捉到距离变化，通过高灵敏度和视觉/串口警报，让全班同学迅速无缝（真的吗）切换回“认真学习”状态。


**项目特性

无线低延迟：基于 ESP-NOW 协议，无需路由器，点对点延迟极低（毫秒级）。放在门口当岗哨，报警器放室内，绝对安全隐蔽。
双端架构：发送端采集并过滤数据，接收端负责较复杂的图形渲染与逻辑计算。
多种工作模式：通过接收端 `BOOT (GPIO 0)` 按键循环切换。
自适应波形图：完美复刻示波器的瀑布流效果，包含距离、速度、相图等。丝滑~
联动警报：内置全局突变检测（Flash），满足条件时通过串口（115200）发送 `start` 与 `stop`，可联动外部蜂鸣器、继电器或震动马达。记得共地~


**BOM

ESP32-S3 核心开发板 * 2 （推荐 N16R8 版本）
VL53L0X 激光测距模块（I2C） * 1 
0.96寸 OLED 屏幕（I2C 接口，128×64） * 1
杜邦线、USB Type-C 数据线若干（废话，当然直接用焊锡来飞我也不反对）


**硬件接线

发送端：
VL53L0X VCC → 3.3V,
VL53L0X GND → GND,（废话）
VL53L0X SDA → GPIO 8,
VL53L0X SCL → GPIO 9,

**接收端：
OLED VCC → 3.3V,
OLED GND → GND,(还是废话）
OLED SDA → GPIO 8,
OLED SCL → GPIO 9,


**软件依赖与烧录（Arduino IDE）

Arduino 库依赖：
[U8g2](https://github.com/olikraus/u8g2)
[VL53L0X](https://github.com/pololu/vl53l0x-arduino) (Pololu)
ESP32 Core (建议 3.x 版本)

烧录步骤：
烧录接收端代码，打开串口监视器（115200），记下打印出的接收端 MAC 地址。
将 MAC 地址填入发送端代码的 `RECEIVER_MAC` 数组中。
烧录发送端代码。上电即可运行.

flash模式的反色触发条件与较长时间总变化量和瞬间变化量有关，目前来看参数能用，至于能不能更好，你行你上。
